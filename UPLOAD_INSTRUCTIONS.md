# Anonymous code-release bundle — upload instructions

This directory is the **audit-fixed code-release bundle** for the ARR submission
"Linearly Readable, Not Robust" (anonymous). To upload:

1. Visit https://anonymous.4open.science and create a new anonymous repository.
2. Drag-and-drop the contents of this directory into the new repo (or upload
   the zipfile and let the service unpack).
3. Copy the resulting URL (looks like https://anonymous.4open.science/r/XXXX/)
   and paste it into §Reproducibility of `latent_sentinel_arr.tex` with a
   `\url{}` wrapper.

## What is INCLUDED

- `code/analysis_emnlp/` — all audit-fixed analysis scripts (.py + .sh) with
  the username-revealing absolute interpreter path sanitized to
  `<conda-env>/bin/python`.
- `data/emnlp2026/**/*.json` — every JSON artifact the paper's tables/figures
  derive from (small; total ~ 0.5 MB).
- `data/emnlp2026/wsd/baseline_scores_*.npz`, `wsc/scores_*.npz`,
  `wsd/scores_*.npz` — small per-sample score caches enabling
  `wsf_tradeoff_uniform.py`, `wsf_native_threshold.py`,
  `pivot_sensitivity.py` to re-run **without GPU**.
- `requirements.txt`, `REPRODUCE.md`, `AUDIT.md`, `CHECK.md`.

## What is EXCLUDED (regenerable from scripts)

- `data/emnlp2026/pivot/hs_*.npz` (~365 MB total, hidden-state caches)
  — regenerated by `pivot_register_erase_remedy.py` (GPU; ~10 min/backbone).
- `data/predictions/**` (~82 MB) — original probe-prediction CSVs from the
  legacy notebooks; re-derivable by running the original probe-training
  scripts.
- `code/probe_training/`, `code/evaluation/*.ipynb`, `code/analysis_figures/*.ipynb`,
  `code/baselines/*.ipynb`, `code/defense_baselines/`, `code/multilingual_eval/`
  — legacy artifacts from the original Latent Sentinel preprint, superseded
  by the audit-fixed scripts in `code/analysis_emnlp/`.

## Anonymity verification

Before upload, this bundle has been programmatically scanned for
identifier leaks (case-insensitive grep over all text files for the configured
identifier regex). The expected count is **0**; see this directory's top-level
`_ANON_VERIFY.txt` for the verification log.
